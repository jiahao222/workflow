# Publication and Confidentiality

This portfolio demo is independently implemented and contains only fictional examples. It is not a copy of the private production repository.

Excluded by design:

- Channel acquisition, downloader, scraping, login, authorization and parsing implementations
- Partner names, account details, cookies, access tokens and internal endpoints
- Customer titles, scripts, operational logs, private databases and media files
- Production-specific prompt templates or optimization recipes
- Binary models, cached data, backups and original Git history

The renderer produces JSON receipts, **not actual videos**. Prompts are illustrative and newly authored.

Before adding any new code or making the repository public, confirm ownership or permission to disclose the material. Automated secret scanning is no substitute for manual IP review.
